## Rules

1. Read the full issue discussion before using it.
2. Record current status and date checked.
3. Distinguish reporter claim from maintainer-confirmed behavior.
4. A closed issue is not automatically a resolved protocol gap.
5. An open issue is not proof of a defect.
6. If normative text settles the question, the matrix cites normative text, not the issue.
7. If the issue exposes an implementation-only defect, do not score the protocol as missing a normative mechanism unless the specification itself supports that conclusion.
8. If no primary source resolves the hypothesis, score the relevant axis `UNKNOWN` or `PARTIAL` according to the frozen rubric; never promote the issue itself to evidence.
